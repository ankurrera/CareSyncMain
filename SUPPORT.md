# Support & Troubleshooting Guide 🙋‍♂️

Thank you for using CareSync! We want to ensure you have the best possible experience when using or developing on this platform.

---

## 1. Getting Help

Before reaching out or opening a new GitHub issue, please review our self-help guides:

* **[Troubleshooting Guide](./docs/TROUBLESHOOTING.md)**: Common runtime errors, build issues, and model compilation fixes.
* **[Developer Onboarding Guide](./docs/DEVELOPER_GUIDE.md)**: Steps to initialize SDKs, start Uvicorn, and run local databases.

---

## 2. Reporting Issues & Requesting Features

If you encounter a bug or have a suggestion:

1. **Search Existing Issues**: Check if someone has already reported the issue or requested the feature.
2. **Open a New Issue**: Use our issue templates to provide:
   - Steps to reproduce the bug.
   - Expected vs. actual behavior.
   - Screen recordings, screenshots, or stack traces (obfuscate any private information).
   - Your local environment details (Flutter doctor output, Python environment info).

---

## 3. Vulnerability Reporting (Security)

> [!IMPORTANT]
> Do NOT open public GitHub issues for security vulnerabilities. Please review [docs/SECURITY.md](./docs/SECURITY.md) for instructions on how to report security issues privately.
